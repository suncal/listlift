ListLift

One click on any Etsy listing page: photo in, SEO title + all 13 tags + description out.

Download the extension (zip)   Source on GitHub

Install (developer mode)

  1. Unzip the download.
  2. Open chrome://extensions, turn on Developer mode.
  3. Click Load unpacked and choose the extension folder.
  4. Deploy extension/proxy/worker.js to Cloudflare, set your own model key with wrangler secret put ANTHROPIC_API_KEY, and paste the Worker URL into PROXY_URL in background.js.

No API key ships inside the extension. Without a proxy URL the generate button shows an explanatory error instead of a listing.

What it does

  • Inline ✨ button and panel on Etsy's listing editor
  • Popup generator that works on any page
  • Usage metering and a $9/month paywall hook (not connected in this preview)
